A tiny program that writes one line of awkward small talk between two robots sharing an elevator: a confession about pressing every floor on purpose, dressed up as a malfunction for the efficiency report. The program writes the line to /output/entry.txt, deterministically, with no network and no dependencies.

## Run it

```sh
python3 main.py
```
